# 0.7.1 verification

The behaviors here were measured on the shipped Studio (SHA-256 `9c8e6304f8a5c87712364c07d945a3fd7b3e0db6e726d8dcf8bbef30bab7b429`) and reusable sprite (`12785b9651513e147c0bc77c384fa4374bf7041e9e564a8500d483fb9878d203`). Both archives rebuild byte-for-byte using the source and inputs archived with this release. The prior editor save and the originally published 0.7.0 Studio are preserved separately in `../inputs/`.

- **Menu highlights.** Native Pen geometry was measured on the expanded header, middle and last rows. At resting scale their left/right/top/bottom insets are 4/6/4/4 Scratch pixels: the one-pixel shift left and two extra pixels of vertical clearance compared with 0.7.0. These margins follow the active panel scale, including the highlighted capsule from which a child opens and to which it returns. The same checks cover the child header, first and last rows while opening, stable, and closing. The pressed/hovered standalone button does not paint a selection wash. See `highlight.json`, `menu-highlight.png`, and `hover-last-stage.png`.
- **Motion.** The first release frame retains the last displayed position, stretch and velocity. In the same throw, the previous Menu jumped 6.63 px on that frame. Held stretch survives reversal; a released control can pass its anchor and settle. The same title and right-hand chevron follow the spring through a submenu's closed position. Root and nested stress tests transfer title ownership to the source within 0.08 stage pixel. See `gesture.json`, `stretch.json`, `timing.json`, `settle.json`, and `menu-hand.json`.
- **Lettering.** Actual TurboWarp WebGL stage before/after shots show the same green-flag scene, on Grid, with Menu finish open. Compare `menu-ink-comparison.png`. Near-uniform transforms use a single stamp of the original artwork. For uneven stretch/partial occlusion the renderer samples the combined face and outline, so joints do not build up opacity. In probes of H, O, é and a rotating chevron at 42% opacity, no sample exceeded 42%. See `opacity.json`, `body.json` and `control-motion.json`.
- **Scratch and TurboWarp.** Both exports pass structural validation without warnings. Live checks used the installed TurboWarp VM with the compiler on and off. Real stage captures used its WebGL renderer at standard and high quality. The editable Studio was then loaded in the designated TurboWarp Desktop window. These checks did not publish a project to the Scratch website.
- **File size.** Studio's project.json is 4,821,700 bytes. Saving it with a settled child menu open produced 4,820,807 bytes; the reusable sprite's sprite.json is 4,959,782 bytes. The sprite was also imported into a separate test project, where its settled open-menu save was 4,779,764 bytes with the compiler off. Let a frame finish before saving: while the interpreter is partway through painting, its temporary drawing lists can briefly put the serialized project above 5 MB. See `native-save.json` and `host-import.json`.
- **Renderer regression checks.** The 42 raw renderer cases, six EffOnly optics cases, ten material checks, and the private-pane interpreter presentation checks passed. No samples from the displayed child disappeared at a frame yield; idle frames emitted no redraw commands. The original assets and existing public example inputs were preserved.
