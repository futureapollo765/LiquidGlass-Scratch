# Preview provenance

The menu preview uses the Studio project’s green-flag loop and the default public Menu example. It starts with the root open and a pointer over the Menu finish row. A native mouse press and release opens that row. Another press and release on the child header returns to the root. The movie presents the interaction at real simulation timing, followed by a half-speed replay. At 30 steps per second, the child first has visible area on frame 12, reverses on frame 75, and is removed by frame 84. No leaf action fires.

The rim comparison renders the same two public block calls on the calibration grid in each Studio version. The Background is a 156×92 rounded rectangle at (−100, 0), with radius 18. The Button is a 164×66 capsule at (100, 0). Both have reflection 0.55, distortion 1, edge 1, highlight 1, light −30, tint 0, transparency 100, brightness 0, blur 0, and quality 1. Both versions use exactly the same pixel crop. There is no exposure or contrast adjustment.

All stage pixels are reconstructed from the actual native Pen lines, Pen points, and costume stamps emitted by the installed TurboWarp Desktop VM. The labels outside the stage are editorial captions. A 30 Hz simulation clock shows the intended choreography without making a claim about desktop playback performance. Neither archive was edited.
